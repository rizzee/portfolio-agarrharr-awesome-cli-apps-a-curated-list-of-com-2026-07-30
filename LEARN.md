# LEARN.md

## 1. Что сделали
- CLI-утилиту на Python для работы с каталогом консольных приложений
- Реализовали поиск и фильтрацию по категориям (академия, погода и др.)
- Использовали `click` для обработки аргументов и `rich` для красивого вывода
- Данные хранятся в JSON с структурой: категория → список приложений (название, описание)

## 2. Что разобрать
- Работу с JSON в Python (`json.load()`)
- Библиотеку `click` для CLI (декораторы `@click.command`, `@click.option`)
- Форматирование вывода через `rich` (таблицы, подсветка)
- Структуру проекта: основной скрипт + данные в отдельном файле
